# 📤 텔레그램 파일 업로더

로컬 컴퓨터에서 GUI를 통해 파일을 선택하고 텔레그램 봇으로 전송하는 파이썬 애플리케이션입니다.

## ✨ 주요 기능

- 🖥️ 사용하기 쉬운 GUI 인터페이스
- 📁 파일 선택 및 업로드
- 💾 봇 토큰 및 채팅 ID 설정 저장
- 📊 실시간 업로드 진행 상태 표시
- 🔒 봇 토큰 보안 (마스킹 처리)
- 📦 다양한 파일 형식 지원

## 📋 사전 준비

### 1. 텔레그램 봇 생성

1. 텔레그램에서 [@BotFather](https://t.me/BotFather)를 검색
2. `/newbot` 명령어로 새 봇 생성
3. 봇 이름과 사용자명 설정
4. **봇 토큰**을 받아서 안전하게 보관

### 2. 채팅 ID 확인

#### 개인 채팅 ID 확인:
1. 봇과 대화 시작 (봇에게 메시지 전송)
2. 브라우저에서 다음 URL 접속:
   ```
   https://api.telegram.org/bot<YOUR_BOT_TOKEN>/getUpdates
   ```
3. 응답에서 `"chat":{"id":` 부분의 숫자가 채팅 ID

#### 그룹 채팅 ID 확인:
1. 봇을 그룹에 추가
2. 그룹에서 아무 메시지나 전송
3. 위와 동일한 방법으로 URL 접속하여 ID 확인
4. 그룹 ID는 보통 `-`로 시작 (예: `-1001234567890`)

## 🚀 설치 및 실행

### 1. 필요한 패키지 설치

```bash
pip install -r requirements.txt
```

또는 개별 설치:

```bash
pip install python-telegram-bot==20.7 requests==2.31.0
```

### 2. 프로그램 실행

```bash
python telegram_uploader.py
```

또는 실행 권한 부여 후:

```bash
chmod +x telegram_uploader.py
./telegram_uploader.py
```

## 📖 사용 방법

### 첫 사용 시

1. **봇 토큰 입력**: 텔레그램 BotFather로부터 받은 봇 토큰 입력
2. **채팅방 ID 입력**: 파일을 전송할 채팅방 또는 개인 채팅의 ID 입력
3. **설정 저장 클릭**: 다음 실행 시 자동으로 불러옵니다

### 파일 업로드

1. **파일 선택** 버튼을 클릭하여 업로드할 파일 선택
2. **업로드** 버튼 클릭
3. 진행 상태 확인
4. 업로드 완료 메시지 확인

## ⚙️ 설정

설정은 자동으로 다음 위치에 저장됩니다:
- **Windows**: `C:\Users\<사용자명>\.telegram_uploader_config.json`
- **macOS/Linux**: `/home/<사용자명>/.telegram_uploader_config.json`

## 📝 제한사항

- **최대 파일 크기**: 50MB (텔레그램 봇 API 제한)
- 더 큰 파일은 분할하거나 압축하여 업로드하세요

## 🔒 보안 주의사항

1. **봇 토큰 보안**
   - 봇 토큰을 절대 다른 사람과 공유하지 마세요
   - 설정 파일은 안전한 곳에 보관하세요
   - 깃허브 등 공개 저장소에 토큰을 업로드하지 마세요

2. **권한 관리**
   - 봇을 불필요한 그룹에 추가하지 마세요
   - 정기적으로 봇 접근 권한을 검토하세요

## 🛠️ 문제 해결

### 업로드 실패 시

1. **봇 토큰 확인**
   - 올바른 형식: `1234567890:ABCdefGHIjklMNOpqrsTUVwxyz`
   - BotFather에서 재확인

2. **채팅 ID 확인**
   - 올바른 형식: 숫자로만 구성 (예: `123456789` 또는 `-1001234567890`)
   - getUpdates API로 재확인

3. **네트워크 연결 확인**
   - 인터넷 연결 상태 확인
   - 방화벽 설정 확인

4. **파일 크기 확인**
   - 50MB 이하인지 확인
   - 필요시 파일 압축
